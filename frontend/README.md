# BestValueBuy

Property marketplace MVP: buy, sell and discover land, apartments, houses and villas.

## Frontend

React + Vite + React Router.

### Run locally

```bash
cd frontend
npm install
npm run dev
```

Open the URL printed by Vite.

## Current milestone

- Responsive marketplace homepage
- Property search and filters
- Property detail page
- Login and registration UI
- Post property form
- Seller dashboard UI
- Sample property data
